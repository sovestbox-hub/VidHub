# VidHub — агрегатор видео со своим плеером

Сайт автоматически собирает ссылки, названия и превью видео с сайтов, которые вы укажете, показывает их
на главной в виде сетки и открывает видео либо в **вашем плеере**, либо на **сайте-источнике**.

```
sources.json ──► crawler.py ──► SQLite (data/vidhub.db) ──► app.py (Flask) ──► браузер
 (ваши сайты)   (парсер)                                    API + страницы     сетка + плеер
```

## Быстрый старт

Нужен Python 3.9+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python seed_demo.py                # демо-данные, чтобы сразу увидеть интерфейс
python app.py                      # сайт: http://127.0.0.1:8000
```

Убрать демо: `python seed_demo.py --clear`.

## Подключение своих сайтов (sources.json)

В файле три шаблона (`enabled: false`) — для HTML-страницы, RSS-ленты и JSON API. Скопируйте нужный,
впишите свой адрес и селекторы, поставьте `"enabled": true`.

**Всегда сначала проверяйте источник, ничего не сохраняя:**

```bash
python crawler.py --test html_example --limit 5
python crawler.py --test html_example --details     # + заглянуть на страницы видео (embed / поток)
```

Команда покажет, сколько блоков найдено и что извлеклось (название, ссылка, превью, длительность).
Если «найдено блоков: 0» — селектор `item` неверный: откройте сайт в браузере → ПКМ по карточке видео →
«Просмотреть код» и найдите класс повторяющегося блока.

### Поля источника

| Поле | Описание |
|---|---|
| `id`, `name` | Короткий идентификатор (латиница) и название, которое увидят посетители |
| `type` | `html` (по умолчанию), `rss` (RSS/Atom) или `json` |
| `url` | Адрес списка. `{page}` заменяется на номер страницы |
| `max_pages`, `start_page`, `page_step` | Сколько страниц брать (по умолчанию 2), с какой начать, шаг нумерации |
| `delay_seconds` | Пауза между запросами к сайту (по умолчанию 1.5) |
| `selectors` | `item` (блок видео), `link`, `title`, `thumb`, `duration`, `preview` — см. ниже |
| `details.fetch` | `true` — заходить на страницу каждого нового видео за embed/потоком |
| `details.max_per_run` | Максимум страниц видео за один запуск (по умолчанию 40) |
| `details.video / embed / stream / thumb / duration` | Свои селекторы для страницы видео (необязательно) |
| `embed_template`, `id_regex` | Построить embed из ссылки: `"https://site/embed/{id}"` + `"/video/(\\d+)"` |

### Язык селекторов

| Запись | Что достаёт |
|---|---|
| `.title` | Текст элемента |
| `img@data-src` | Атрибут `data-src` |
| `img@data-src\|src` | Первый непустой из атрибутов (ленивые превью) |
| `@href` | Атрибут самого блока |
| `a@title\|\|h3` | Запасной вариант: если первого нет — взять второй |

Для RSS двоеточие в пространствах имён заменяется дефисом: `media:thumbnail` → `media-thumbnail`.
Для JSON пути пишутся через точку (`thumbs.0.src`), а в значениях работают шаблоны `{поле}`.

### Как видео попадает в плеер

Для каждого видео ищется способ показать его у вас:

1. **Прямой файл/поток** (`.mp4`, `.webm`, `.m3u8`) → ваш собственный плеер.
2. **Embed** (iframe-плеер источника: `og:video`, `embed_template`, поле `embed` в API) → встраивается на странице.
3. Ничего не найдено → клик ведёт на страницу видео **на сайте-источнике**.

Поведение клика задаётся в `config.json`, `click_behavior`:
`auto` (по умолчанию: плеер, если возможно, иначе источник), `player` (всегда страница с плеером),
`redirect` (всегда сразу на сайт-источник).

## Настройки (config.json)

| Параметр | Значение по умолчанию |
|---|---|
| `site_name`, `tagline` | Название и подзаголовок сайта |
| `host`, `port` | `127.0.0.1`, `8000` (для доступа извне: `0.0.0.0`) |
| `click_behavior` | `auto` / `player` / `redirect` |
| `per_page` | 24 видео на «страницу» ленты |
| `age_gate` | `true` — показывать окно «Вам есть 18 лет?» (адрес выхода — `age_exit_url`) |
| `embed_sandbox` | `true` — iframe с ограничениями. Если чужой плеер не запускается, поставьте `false` |
| `crawl_on_start`, `crawl_interval_minutes` | Сбор при старте и раз в N минут (`0` — не повторять) |
| `max_videos` | Сколько видео хранить |
| `force_https_media` | Превращать `http://` превью/потоков в `https://` |
| `admin_token` | Пароль для админ-запросов. Пусто — админ-API выключен |

Цвета сайта меняются в начале `static/css/style.css` (блок `:root`).

## Администрирование

```bash
# запустить сбор прямо сейчас
curl -X POST -H "X-Admin-Token: ВАШ_ТОКЕН" http://127.0.0.1:8000/api/admin/crawl
# состояние источников: сколько найдено, ошибки
curl -H "X-Admin-Token: ВАШ_ТОКЕН" http://127.0.0.1:8000/api/admin/status
# скрыть видео (например, по жалобе); при следующем сборе оно не вернётся
curl -X DELETE -H "X-Admin-Token: ВАШ_ТОКЕН" http://127.0.0.1:8000/api/admin/videos/123
```

Собрать вручную из консоли: `python crawler.py` (или `--source ID`). Для cron/планировщика поставьте
`"crawl_interval_minutes": 0` и запускайте `python crawler.py` по расписанию.

## Плеер

MP4/WebM/HLS (выбор качества), перемотка с подсказкой времени и буфером, скорость, громкость, PiP, полный экран,
продолжение просмотра с того же места, управление с клавиатуры и жестами.

| Клавиша | Действие | Клавиша | Действие |
|---|---|---|---|
| `Пробел` / `K` | Пауза | `F` | Полный экран |
| `←` / `→` | −5 / +5 секунд | `M` | Звук вкл/выкл |
| `J` / `L` | −10 / +10 секунд | `↑` / `↓` | Громкость |
| `0`–`9` | Перейти на 0–90 % | `<` / `>` | Скорость |

Двойной клик/тап по левой трети видео — назад на 10 с, по правой — вперёд, по центру — полный экран.
HLS подгружает библиотеку hls.js с CDN; чтобы хостить её у себя, положите файл в `static/js/` и добавьте перед
`player.js` строку `window.VPLAYER_HLS_URL = "/static/js/hls.min.js"`.

## Публикация на сервере

```bash
pip install -r requirements.txt           # waitress уже входит
# config.json: "host": "127.0.0.1", "port": 8000, "admin_token": "длинный-случайный-пароль"
python app.py                             # запускайте через systemd/supervisor
```

Перед приложением поставьте nginx (HTTPS, например через Let's Encrypt) с `proxy_pass http://127.0.0.1:8000;`.
Приложение работает одним процессом (сбор идёт фоновым потоком) — не запускайте несколько копий.

## Важно: права и правила чужих сайтов

- Перед подключением сайта прочитайте его условия использования и `robots.txt`. Многие сайты запрещают автоматический
  сбор. **Самый надёжный путь — RSS-ленты, API и партнёрские программы**, где владельцы сами дают фиды и embed-плееры.
- Названия, превью и видео защищены авторским правом. Сайт ведёт читателей на оригинал и указывает источник — оставьте
  это так и не копируйте сами видеофайлы к себе. Для жалоб правообладателей есть быстрое скрытие (`DELETE` выше);
  опубликуйте на сайте контакт для обращений.
- Если среди источников есть материалы 18+, включите `age_gate` и проверьте требования законов вашей страны
  и страны ваших посетителей к такому контенту и проверке возраста — при необходимости проконсультируйтесь с юристом.
- Прямые ссылки на файлы чужих CDN часто подписаны, временны или закрыты от встраивания. Надёжнее всего работает embed.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Видео не появляются | `python crawler.py --test ID`; смотрите ошибки в `GET /api/admin/status` |
| «найдено блоков: 0» | Неверный `selectors.item`, либо сайт отдаёт список через JavaScript (тогда ищите его API/RSS и используйте `type: json`/`rss`) |
| Нет превью | Проверьте `thumb` (`img@data-src\|src`); сайт мог запретить показ картинок на чужих страницах |
| Чужой плеер пуст | Поставьте `"embed_sandbox": false`; проверьте, разрешает ли источник встраивание |
| Поток не играет | Ссылка может быть временной или закрытой по Referer — используйте embed |
